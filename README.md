# คณิตศาสตร์ 12* (ค 33206) - ชุดที่ 12

เว็บแอปเอกสารประกอบการสอนวิชาคณิตศาสตร์ ประกอบด้วยโจทย์ A-Level ชุดที่ 12 จำนวน 30 ข้อ เฉลยแบบพิมพ์ กระดาษทดออนไลน์ และไฟล์ PDF รวมโจทย์ครบ 30 ข้อ

## คุณสมบัติ

- โจทย์ คำตอบ และเฉลย 30 ข้อจากเอกสารชุดที่ 12 จัดพิมพ์สมการด้วย KaTeX
- เปิด-ปิดเฉลยและกระดาษทดแยกแต่ละข้อ
- ดาวน์โหลด PDF รวมโจทย์ 30 ข้อ และ PDF แยกรายข้อ
- ใช้งานได้ทั้งคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- ดาวน์โหลดกระดาษทดเป็นไฟล์ภาพได้

## การใช้งานในเครื่อง

```bash
pnpm install
pnpm run build:netlify
pnpm run preview:netlify
```

Netlify ใช้ build command `pnpm run build:netlify` และ publish directory `netlify-dist`

ออกแบบและพัฒนาโดย ครูนพพล สุขภิรมย์ ครูชำนาญการพิเศษ กลุ่มสาระการเรียนรู้คณิตศาสตร์ โรงเรียนศรีสวัสดิ์วิทยาคารจังหวัดน่าน
